# Portfolio Blueprint

Build me a modern personal portfolio website.

I want the site to feel professional, clean, modern, and slightly tech-focused. It should have a dark theme inspired by the Ghoul Trooper color palette from Fortnite, but it should NOT look like a gaming website.

Use:

Black as the main background

Teal #00FFBF as the primary accent color

White/off-white for text

Dark blue or blue-gray as supporting colors

Pink #FF0088 only very sparingly for small highlights or hover effects

The overall priority should be: professional first, themed second.

Layout

Use a fixed sidebar on the left side of the screen.

The sidebar should include both icons and text for:

About

Courses

Experience

Portfolio

When a user clicks one of these sections, the main content area should switch to that section instead of making the user scroll through one long page.

The active section in the sidebar should be clearly highlighted, preferably with the teal accent color or a subtle teal glow.

On mobile, the sidebar should turn into a clean hamburger/menu navigation.

About Section

This should act as the homepage/default section.

Include:

Profile picture

Name

Short introduction

Brief summary about being a college student

Areas of interest such as AI, backend development, frontend development, data, and technology

Buttons/icons for GitHub, LinkedIn, Resume, and Email

Use realistic placeholder text and a placeholder image for now. I will replace the content later.

Courses Section

Create a collection of course cards.

Each card should display all information at once:

Course name

Course code

Category

Short course description

Add filter buttons for:

All

Computer Science

Data Science

Economics

When a filter is selected, only courses from that category should appear.

Use realistic placeholder courses for now.

Experience Section

Make this similar to the clean layout used on LinkedIn profiles.

Each experience should show:

Company logo

Role title

Company name

Dates

Location

Short description or bullet points

Stack the experiences vertically.

Keep the layout clean and professional rather than overly decorative.

Use realistic placeholder experiences for now.

Portfolio Section

Create modern project cards.

Each project should include:

Project name

Short description

Technologies used

Optional project screenshot/image

GitHub button

Live Demo button if applicable

The design should make it easy to add more projects later.

Use realistic placeholder projects for now.

Animations and Interactions

Use subtle animations only.

Examples:

Slight card lift on hover

Subtle teal border/glow on hover

Smooth transitions when switching sections

Smooth sidebar active-state animation

Light fade-in when a section appears

Avoid excessive animations, gradients, or flashy effects.

General Design

Use:

Strong typography

Good spacing

Rounded but not overly rounded cards

Clean borders

Minimal clutter

Responsive design

Modern professional look

Avoid:

Skill percentage bars

Generic “developer portfolio” clichés

Excessive neon

Heavy gradients

Gaming-style UI

Overly futuristic design

For now, focus on the overall design, layout, responsiveness, and interaction. Use placeholder content throughout because I will replace the actual text, courses, experiences, projects, images, and links later.
